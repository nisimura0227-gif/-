# 公式LINE Messaging API・LIFF 設定手順（現場めし）

サイト側の実装（新規注文通知・支払い確認・毎朝のリマインドなど）は完了しています。
この手順書は、それを実際に動かすために **LINE Developers 側で必要な設定** をまとめたものです。

すでに `公式LINEアカウント_新規開設手順.md` でアカウントを開設済み、
`公式LINE_リッチメニュー設定手順.md` でリッチメニューを設定済みであることを前提にしています。

完了すると、次のことができるようになります。

- 新しい注文・支払い申告が入るたびに、担当者のLINEへ自動通知
- 担当者はLINEの「受け取り確認」ボタンをタップするだけで支払い確定
- 注文者へ、注文完了・支払い確認をLINEで自動通知
- 毎朝6:30に「本日の受付中です」のリマインドを自動送信
- 前日15:00（明日の注文締切）に、注文状況のサマリーを担当者へ自動通知

---

## 全体の流れ

1. Messaging APIを有効にする（LINE Official Account Manager）
2. チャネルアクセストークン・チャネルシークレットを取得する（LINE Developers）
3. LIFFアプリを作成する（LINE Developers）
4. Webhookを設定する（LINE Developers・LINE Official Account Manager）
5. リッチメニューのリンクをLIFF用に変更する
6. Vercelに環境変数を設定する
7. 動作確認

所要時間は30分程度です。

---

## 1. Messaging APIを有効にする

1. https://manager.line.biz/ を開き、対象のアカウントを選ぶ
2. 左メニュー「設定」→「Messaging API」を開く
3. 「Messaging APIを利用する」を選択し、案内に沿って進める（プロバイダーの選択・作成が必要な場合は新規作成でOK）
4. 完了すると、このアカウントに対応する「チャネル」がLINE Developersコンソールに作成されます

---

## 2. チャネルアクセストークン・チャネルシークレットを取得する

1. https://developers.line.biz/console/ を開き、さきほど作成されたプロバイダー・チャネルを選ぶ
2. 「Messaging API設定」タブを開く
3. ページ下部の **「チャネルアクセストークン（長期）」** で「発行」をクリックし、表示された文字列をコピーしておく
   → これが `LINE_CHANNEL_ACCESS_TOKEN` になります
4. 「チャネル基本設定」タブを開き、**「チャネルシークレット」** をコピーしておく
   → これが `LINE_CHANNEL_SECRET` になります

どちらも第三者に知られると、なりすまし送信やWebhook偽装が可能になってしまう重要な情報です。Vercelの環境変数以外（チャット・メール等）に貼り付けないでください。

---

## 3. LIFFアプリを作成する

LIFFは、LINEアプリ内のブラウザでサイトを開いたときに「誰が開いたか（LINEアカウント）」を安全に取得するための仕組みです。これによって、注文完了・支払い確認のお知らせを本人のLINEへ届けられるようになります。

> **注意（2019年11月以降の仕様変更）**
> 以前はMessaging APIチャネルに直接LIFFアプリを追加できましたが、現在は **「LINEログイン」チャネル** にのみLIFFアプリを追加できます。手順4の「Bot link feature」で元のMessaging APIチャネルと紐付けることで、LIFFで取得したLINEユーザーIDがMessaging APIの通知先ユーザーIDと一致するようになります。

1. LINE Developersコンソールで、プロバイダーのトップ画面に戻る（画面左上のパンくずの、一番左側のプロバイダー名をクリック）
2. 「チャネルを作成する」をクリックし、チャネルタイプで **「LINEログイン」** を選ぶ（Messaging APIとは別チャネルとして新規作成する）
3. 必要事項を入力して作成する

| 項目 | 入力内容 |
|---|---|
| チャネル名 | 何でもよい（例：`現場めし ログイン`） |
| チャネル説明 | 何でもよい |
| アプリタイプ | 「ウェブアプリ」にチェック |

4. 作成した「LINEログイン」チャネルを開き、「LIFF」タブ →「追加」で以下を入力する

| 項目 | 入力内容 |
|---|---|
| LIFFアプリ名 | `現場めし` |
| サイズ | `Full` |
| エンドポイントURL | サイトの公開URL（例：`https://bento-order-app-weld.vercel.app`） |
| Scope | `profile` にチェック（`openid` も自動でチェックされます） |
| 友だち追加オプション（ボットリンク機能） | `On (Normal)` でよい（同じプロバイダー内にMessaging APIチャネルが1つしかない場合は自動的にそのチャネルと連携され、連携先を選ぶ画面は出ません） |

5. 「追加」をクリックすると、`2011028925-e4zB0jjR` のような「数字-英数字」の形式のLIFF IDが発行されます
   → これが `NEXT_PUBLIC_LIFF_ID` になります

> **重要：作成する場所を間違えないでください**
> チャネルを新規作成する際、プロバイダーを選ぶ画面で誤って「新しいプロバイダーを作成」してしまうと、Messaging APIチャネルと別のプロバイダーになってしまい、LIFFのユーザーIDが一致しなくなります。必ず既存の「現場めし」プロバイダーを選んでからチャネルを作成してください。

> **補足：LIFF URLでページを直接指定できます**
> 通知メッセージのボタンや、あとで説明するリッチメニューでは、
> `https://liff.line.me/{LIFF ID}/order/today` のように末尾にパスを付けると、
> エンドポイントURLの `/order/today` を直接開けます（`/order/tomorrow` も同様）。

### 3-1. LINEログインチャネルを「公開」する（必須）

作成直後のLINEログインチャネルは「開発中」の状態で、これはテスターとして登録した人しかログインできません。**現場の全員が使えるようにするには「公開」が必須です。**

1. 作成した「〇〇 ログイン」チャネルのチャネル基本設定を開く
2. ステータス表示の「開発中」をクリック
3. 「チャネルを公開しますか？」の確認画面で「公開」をクリック

> **注意：この操作は取り消せません**（元に戻すにはチャネルを削除して作り直す必要があります）。ただし全員に開放するのは今回の目的そのものなので、内容としては問題ありません。

## 4. Webhookを設定する

これまで「Webhookはオフのままでよい」とご案内していましたが、支払い確認ボタンを使うために **オンにする必要があります**。

1. LINE Developersコンソールの「Messaging API設定」タブを開く
2. 「Webhook設定」の **Webhook URL** に以下を入力（サイトのURLに置き換えてください）

```
https://（サイトの公開URL）/api/line/webhook
```

3. 「検証」をクリックし、成功することを確認する（先に手順6の環境変数設定・再デプロイを済ませてから検証してください）
4. **「Webhookの利用」を オン にする**
5. LINE Official Account Manager（https://manager.line.biz/）の「設定」→「応答設定」を開く
   - 「応答メッセージ」：**オフ**（Webhookで処理するメッセージと混同しないため）
   - 「Webhook」：**オン**

## 5. リッチメニューのリンクをLIFF用に変更する

`公式LINE_リッチメニュー設定手順.md` で設定した2つのリンクのうち、**「お弁当注文」側だけ** LIFF URLに変更します（管理画面側は変更不要です）。

1. LINE Official Account Manager →「トークルーム管理」→「リッチメニュー」→ 対象メニューを編集
2. 「A（左：お弁当注文）」のURLを、次のいずれかに変更する

| 用途 | URL |
|---|---|
| トップページへ（今日・明日どちらも選べる画面・**推奨**） | `https://liff.line.me/{LIFF ID}` |
| 今日の注文へ直接 | `https://liff.line.me/{LIFF ID}/order/today` |
| 明日の注文へ直接 | `https://liff.line.me/{LIFF ID}/order/tomorrow` |

**基本はトップページへのリンクを推奨します。** 今日・明日どちらの注文も1つのボタンから選べるほうが分かりやすいためです。「今日の注文へ直接」を使う場合、サイト側で`liff.state`を検知して該当ページへ自動的に移動する処理を実装済みです（`components/LiffInit.tsx`）。

3. 「B（右：管理画面）」は変更不要（`/admin/login` のままでOK）
4. 保存する

---

## 6. Vercelに環境変数を設定する

1. Vercelのプロジェクトページ →「Settings」→「Environment Variables」を開く
2. 以下を追加する

| Name | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | 手順2で取得したチャネルアクセストークン |
| `LINE_CHANNEL_SECRET` | 手順2で取得したチャネルシークレット |
| `NEXT_PUBLIC_LIFF_ID` | 手順3で取得したLIFF ID |
| `NEXT_PUBLIC_SITE_URL` | サイトの公開URL（例：`https://bento-order-app-weld.vercel.app`） |
| `CRON_SECRET` | 適当な長いランダム文字列（例：`openssl rand -hex 32`、なければ英数字を30文字ほど適当に打ち込む） |

3. 「Deployments」タブ →「Redeploy」で再デプロイする
4. 再デプロイ完了後、手順4の「Webhook URL の検証」を行う

### Cron（定時通知）について

`vercel.json` に、毎朝6:30と前日15:00の定時通知の設定を含めています。Vercelへのデプロイ時に自動的に有効になります（追加の設定は不要です）。無料（Hobby）プランでも、1日1回までの定時実行は利用できます。

## 7. 動作確認

- [ ] スマホのLINEで公式アカウントのトーク画面を開き、リッチメニューの「お弁当注文」から注文ページが開く
- [ ] 名前を入力して注文する（初回はLINEログインの確認画面が一瞬出ることがあります）
- [ ] 注文完了後、本人のLINEに「注文を受け付けました」という通知が届く
- [ ] 管理画面の「設定」→「LINE通知の受け取り先」から、担当者自身のLINEを登録する（複数人登録できます）
- [ ] 別の名前で注文すると、登録した管理者のLINEに新規注文の通知が届く
- [ ] 注文完了画面の「支払いました」ボタンを押すと、管理者のLINEに「受け取り確認」ボタン付きの通知が届く
- [ ] 管理者がそのボタンを押すと、注文者本人のLINEに「お支払いを確認しました」が届く
- [ ] 管理画面の注文一覧でも、支払い状況が「支払い済み」になっている

うまく届かない場合は、まずVercelの「Deployments」→ 対象デプロイの「Functions」ログでエラーが出ていないか確認してください。

## よくある質問

**Q. LINE連携の設定をしなくても、サイトは使える？**
使えます。上記の環境変数をすべて未設定のままにしておけば、これまで通り「注文・管理画面」のみのサイトとして動作します。あとから設定を追加しても、既存の注文データに影響はありません。

**Q. 管理者が複数人いる場合は？**
管理画面の「設定」→「LINE通知の受け取り先」から、それぞれのLINEアカウントを登録してください。全員に同じ通知が届きます。

**Q. チャネルアクセストークンの有効期限は？**
「長期」トークンは基本的に無期限です（LINE側の仕様変更や再発行を行わない限り有効です）。

**Q. Webhook検証がエラーになる**
- 環境変数を設定後、再デプロイが完了しているか確認してください
- Webhook URLの末尾が `/api/line/webhook` になっているか確認してください
- チャネルシークレットが正しくコピーされているか確認してください（前後の空白に注意）
