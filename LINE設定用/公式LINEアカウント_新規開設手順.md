# 公式LINEアカウント 新規開設手順（現場めし）

「現場めし」への入り口にする公式LINEアカウントを、ゼロから作る手順です。
アカウントの作成はご本人の携帯電話番号での認証が必要なため、代理では行えません。
この手順書を見ながら、10分ほどで完成します。

---

## 事前に用意するもの

| 項目 | 内容 |
|---|---|
| メールアドレス | 登録に使います。会社のものでも個人のものでもOK |
| 携帯電話番号 | SMS（またはお電話）による本人確認に使います |
| アカウント名（案） | 例：「現場めし」または会社名（例：〇〇建設） |
| アイコン画像（あれば） | `public/icon.svg` を元にした現場めしのロゴでも可。なくても後から設定できます |

※ LINE公式アカウントは無料で開設できます（初期費用0円、メッセージ配信数に応じて有料プランあり。今回の使い方＝リッチメニューからサイトを開くだけなら無料プランで十分です）。

---

## 手順

### 1. 開設ページを開く

パソコンのブラウザ（Google Chrome推奨）で以下を開きます。

https://entry.line.biz/start/jp/

「LINE公式アカウントをはじめる」ボタンをクリックします。

### 2. ビジネスIDを登録する

「LINEアカウントで登録」または「メールアドレスで登録」のどちらかを選びます。

- **LINEアカウントで登録**：普段お使いのLINEアプリでQRコードを読み取って登録。一番早いのでおすすめです。
- **メールアドレスで登録**：メールアドレスを入力 →「登録用のリンクを送信」→ 届いたメール内の「登録画面に進む」をクリック → 氏名とパスワードを設定 → 利用規約に同意して「登録」

### 3. 携帯電話番号でSMS認証

登録が完了すると認証画面になります。

- 携帯電話番号を入力し、届いたSMSの認証番号を入力
- SMSが受け取れない場合は「SMSが受信できない場合はこちら」から電話（自動音声）でも認証できます

### 4. LINE公式アカウントの情報を入力

以下を入力します。

| 項目 | おすすめの入力内容 |
|---|---|
| アカウント名 | `現場めし`（利用者にはこの名前で表示されます） |
| 業種 | 建設業、または「その他」の中から近いものを選択 |
| 地域 | 実際の地域を選択 |

### 5. ビジネスマネージャー組織への接続（必須）

2025年6月から、LINE公式アカウントの作成には「ビジネスマネージャー」という組織との連携が必須になりました。

- すでに組織を持っていなければ、画面の案内に従って新規で組織を作成（会社名や担当者情報を入力するだけです）
- 内容を確認し、「確認」→ 内容に間違いがなければ「アカウントを作成」

### 6. 完了

管理画面（LINE Official Account Manager）にログインできれば、アカウント開設は完了です。

これで公式LINEアカウントができました。次は、このアカウントに「お弁当注文」と「管理画面」のボタンを表示させる番です。
**同じフォルダ内の `公式LINE_リッチメニュー設定手順.md` に進んでください。**

## 開設後、最初にやっておくと良い設定

管理画面（https://manager.line.biz/）の「設定」から変更できます。

| 設定項目 | おすすめ |
|---|---|
| プロフィール画像 | 現場めしのロゴ、または会社ロゴを設定 |
| あいさつメッセージ | 「友だち追加ありがとうございます。下のメニューから『お弁当注文』を選んでください」など、初回に届く自動メッセージ |
| 応答設定 → Webhook | オフのままでOK（LINEでの通知・支払い確認機能を使う場合は `公式LINE_MessagingAPI・LIFF設定手順.md` の案内に従ってオンにします） |
| 応答設定 → 応答メッセージ | オフ、または簡単な自動返信のみでOK |
| 友だち追加時のあいさつメッセージ | オンにしておくと、追加した人に使い方が伝わりやすくなります |

## よくある質問

**Q. 個人のLINEアカウントと公式アカウントは別物？**
はい、別物です。開設時に個人のLINEでログインして登録しても、できあがるのは会社・お店として使う「公式アカウント」で、個人のトークや友だちリストとは完全に分かれています。

**Q. 料金は本当に無料？**
基本機能（今回のようにリッチメニューでリンクを表示するだけの使い方）は無料プランの範囲内で問題ありません。無料プランには月間のメッセージ配信数に上限がありますが、今回は個別メッセージを配信しない使い方なので上限を気にする必要はありません。

**Q. 担当者が変わったら？**
LINE Official Account Managerの「権限管理」から、他のメンバーを管理者として追加できます。複数人で管理画面にアクセスしたい場合はここから追加してください。

**Q. すでに会社の公式LINEがある場合は？**
新しく作らず、既存のアカウントにリッチメニューを追加するだけで対応できます。その場合は `公式LINE_リッチメニュー設定手順.md` から始めてください。
