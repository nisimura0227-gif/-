# 公式LINE リッチメニュー 設定手順（現場めし）

> LINEでの新規注文通知・支払い確認機能まで使う場合は、この手順のあとに
> `公式LINE_MessagingAPI・LIFF設定手順.md` の手順5で「お弁当注文」のリンク先を
> LIFF URLに変更する必要があります。まずはこの手順通りに設定してください。

公式LINEのトーク画面の下に、いつも出ているメニューを作ります。
みんなはここから毎日サイトを開くので、URLを覚える必要がなくなります。

完成イメージ:

```
┌─────────────────┬─────────────────┐
│   お弁当注文     │    管理画面      │
│ 毎日の注文はこちら │    担当者用      │
└─────────────────┴─────────────────┘
```

---

## 用意するもの

**リッチメニュー画像**
このフォルダの `リッチメニュー画像_2500x843.png` をそのまま使えます。
（LINEの規格に合わせて作ってあります。作り直す必要はありません）

**リンク先のURL**（あとでコピーして使います）

| ボタン | URL |
|---|---|
| 左：お弁当注文 | `https://bento-order-app-weld.vercel.app/` |
| 右：管理画面 | `https://bento-order-app-weld.vercel.app/admin/login` |

## 手順

### 1. LINE Official Account Manager を開く

パソコンのブラウザで下記を開き、公式LINEのアカウントでログインします。

https://manager.line.biz/

※ スマホアプリ（LINE公式アカウント アプリ）からでも設定できますが、
　 画面が広いパソコンの方が領域の設定がやりやすいです。

### 2. リッチメニューの作成画面へ

1. 対象のアカウントを選ぶ
2. 左メニューの **「トークルーム管理」** をクリック
3. **「リッチメニュー」** をクリック
4. 右上の **「作成」** をクリック

### 3. 表示設定

| 項目 | 入力内容 |
|---|---|
| タイトル | `現場めしメニュー`（管理用の名前。利用者には見えません） |
| 表示期間 | 開始日を今日にする。終了日は長め（例：2030/12/31）にしておくと切れません |
| メニューバーのテキスト | `メニュー` |
| メニューのデフォルト表示 | **表示する** |

> 表示期間の終了日を過ぎるとメニューが消えてしまうので、長めに設定してください。

### 4. コンテンツ設定 → テンプレートを選ぶ

1. **「テンプレートを選択」** をクリック
2. 「小」のグループから、**左右2分割**のテンプレートを選ぶ

```
┌────────┬────────┐
│    A    │    B    │
└────────┴────────┘
```

3. **「選択」** をクリック

### 5. 画像をアップロード

1. **「背景画像をアップロード」** をクリック
2. `リッチメニュー画像_2500x843.png` を選ぶ
3. プレビューに表示されればOK

### 6. アクション（リンク先）を設定

テンプレートのA・Bそれぞれに、リンク先を設定します。

**A（左：お弁当注文）**

| 項目 | 入力内容 |
|---|---|
| アクション | リンク |
| URL | `https://bento-order-app-weld.vercel.app/` |
| アクションラベル | `お弁当注文` |

**B（右：管理画面）**

| 項目 | 入力内容 |
|---|---|
| アクション | リンク |
| URL | `https://bento-order-app-weld.vercel.app/admin/login` |
| アクションラベル | `管理画面` |

> URLは手で打たず、この手順書からコピーして貼り付けてください。1文字違うと開きません。

### 7. 保存

右下の **「保存」** をクリックして完了です。

## 動作確認

スマホのLINEで公式アカウントのトーク画面を開いて、次を確認してください。

- [ ] 画面下にメニューが出ている（出ていなければ、メニューバーの `∨` `∧` をタップ）
- [ ] 「お弁当注文」をタップ → 現場めしのトップページが開く
- [ ] 「管理画面」をタップ → 管理者ログイン画面が開く
- [ ] 管理者ログインすると、次回からはログインなしで管理画面に入れる（30日間）

## よくある質問

**Q. メニューが表示されない**
表示期間の開始日が未来になっていないか、「メニューのデフォルト表示」が「表示する」になっているかを確認してください。

**Q. 画像を自分で作り直したい**
以下の条件を満たせば差し替えできます。

- サイズ：2500×843 px（今回のテンプレートの場合）
- 形式：JPG / JPEG / PNG
- 容量：1MB以下

**Q. 全員に管理画面を見られたくない**
管理画面はパスワードで保護されているので、ボタンが見えても中身は開けません。
それでも隠したい場合は、リッチメニューを1ボタン（お弁当注文のみ）にして、
担当者だけがブラウザのお気に入りから管理画面を開く運用にもできます。

**Q. サイトのURLが変わったら**
リッチメニューのアクション設定でURLを変更して保存し直してください。

## 補足：ホーム画面にも追加できます

LINEから開いたあと、ブラウザで開き直して「ホーム画面に追加」すると、
スマホのホーム画面に **現場めし** のアイコンが並びます。
LINEを経由せず1タップで開けるので、こちらの方が早い人もいます。

- iPhone：Safariで開く →「共有」→「ホーム画面に追加」
- Android：Chromeで開く →「︙」→「ホーム画面に追加」
